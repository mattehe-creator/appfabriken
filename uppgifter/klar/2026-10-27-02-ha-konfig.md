## Uppgift
Skapa i paketet `se.tmconnect.rostfangst.ha`:

```kotlin
data class HaKonfig(val adress: String, val token: String, val todoEntity: String)

enum class HaSteg { HANDELSE, TODO, ASSIST }

fun haKonfig(adress: String, token: String, todoEntity: String): HaKonfig?
fun haSteg(typ: ForslagTyp, konfig: HaKonfig?): List<HaSteg>
```

`haKonfig`:
- Adressen normaliseras med `normaliseraHaAdress`. Ger den `null` blir resultatet `null`.
- Token trimmas. Tom token ger `null`.
- `todoEntity` trimmas (får vara tom).

`haSteg`:
- `konfig == null` ger tom lista.
- ANTECKNING ger tom lista.
- HEM ger `[ASSIST]`.
- ATT_GORA ger `[HANDELSE, TODO]` om `todoEntity` inte är tom, annars `[HANDELSE]`.
- KALENDER, PAMINNELSE och FRAGA ger `[HANDELSE]`.

## Exempel
- `haKonfig(" http://ha.local:8123/ ", " abc ", " todo.att_gora ")` ger `HaKonfig("http://ha.local:8123", "abc", "todo.att_gora")`.
- `haKonfig("ha.local", "abc", "")` ger `null` (saknar http).
- `haKonfig("http://ha.local:8123", "  ", "")` ger `null`.
- `haSteg(ForslagTyp.ATT_GORA, HaKonfig("http://a", "t", ""))` ger `[HANDELSE]`.
- `haSteg(ForslagTyp.ATT_GORA, HaKonfig("http://a", "t", "todo.x"))` ger `[HANDELSE, TODO]`.
- `haSteg(ForslagTyp.HEM, HaKonfig("http://a", "t", ""))` ger `[ASSIST]`.
- `haSteg(ForslagTyp.KALENDER, null)` ger `[]`.
- `haSteg(ForslagTyp.ANTECKNING, HaKonfig("http://a", "t", "todo.x"))` ger `[]`.
