## Uppgift
Skapa i paketet `se.tmconnect.rostfangst.ha`:

```kotlin
sealed interface HaUtfall {
    data class Ok(val kropp: String) : HaUtfall
    data class Fel(val text: String) : HaUtfall
}

interface HaKlient {
    fun skickaHandelse(json: String): HaUtfall   // POST <adress>/api/events/rostfangst_fangst
    fun laggTillTodo(json: String): HaUtfall     // POST <adress>/api/services/todo/add_item
    fun assist(text: String): HaUtfall           // POST <adress>/api/conversation/process
}

class HaHttpKlient(
    private val adress: String,
    private val token: String,
    private val transport: HttpTransport = HttpURLConnectionTransport(),
) : HaKlient
```

- Alla anrop skickar rubrikerna `Authorization: Bearer <token>` och `Content-Type: application/json`.
- `skickaHandelse` och `laggTillTodo` skickar `json` oförändrad som kropp.
- `assist` skickar kroppen `{"text":"<text>","language":"sv"}`. Koda texten som i `HaTodo.kt` (citattecken, bakstreck, radbrytningar) med en privat funktion i filen.
- Status 200–299 ger `HaUtfall.Ok(svar.kropp)`. Annan status ger `HaUtfall.Fel(haFelText(status, null))`.
- Om transporten kastar `java.io.IOException` (även `SocketTimeoutException`): `HaUtfall.Fel(haFelText(null, undantag::class.simpleName ?: "IOException"))`.
- Token och adress får aldrig finnas i en `Fel`-text.

## Exempel
I testet: en falsk `HttpTransport` som sparar url, rubriker och kropp och returnerar ett valt `HttpSvar`. Adress `http://ha.local:8123`, token `abc`.
- `skickaHandelse("{\"typ\":\"KALENDER\"}")` med svar 200 "[]": url `http://ha.local:8123/api/events/rostfangst_fangst`, rubriken `Authorization` är `Bearer abc`, kroppen oförändrad, resultat `Ok("[]")`.
- `laggTillTodo(...)` går till `http://ha.local:8123/api/services/todo/add_item`.
- `assist("tänd \"lampan\"")`: url `.../api/conversation/process`, kroppen `{"text":"tänd \"lampan\"","language":"sv"}` (med bakstreck före citattecknen).
- Svar 401: `Fel("Token nekas, skapa en ny i Home Assistant.")`, och texten innehåller inte `abc`.
- Transporten kastar `java.net.SocketTimeoutException()`: `Fel("Når inte Home Assistant just nu.")`.
