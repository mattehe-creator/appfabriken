## Vad som saknades
- Ingen implementation alls i de två tillåtna Kotlin-filerna — bara flytt av uppgiftsfilen till `uppgifter/pagar/`.
- `KopListaSkarm` tar redan emot `proDialogSynlig`, `onStangProDialog` och `onKopPro` (från uppgift 19) men visar ingen dialog. När `proDialogSynlig == true` ska en Material 3 `AlertDialog` renderas (samma mönster som borttagningsdialogen i `KopDetaljSkarm.kt`).
- Primär knapp ska anropa `onKopPro` med en `Activity` (t.ex. `LocalContext.current as Activity` i confirm-knappens `onClick`, eller `context.findActivity()` om du redan har ett mönster — håll det enkelt och säkert).
- `MainActivity` ska koppla `onKopPro = { proKalla.kop(it) }` (eller motsvarande lambda som anropar `proKalla.kop(activity)`), inte bara lämna befintlig `viewModel::kopPro` om du inte också implementerar dialogen.

## Uppgift
Visa en `AlertDialog` (Material 3) i `KopListaSkarm` när `proDialogSynlig` är true:

1. **Titel:** `R.string.pro` (kort och tydlig).
2. **Text:** `R.string.pro_forklaring`, och under det (samma `text`-block eller ny rad) `R.string.pro_grans_nadd`.
3. **Primär knapp (confirm):** text `R.string.pro_las_upp`, tryckyta minst 48 dp (`Modifier.heightIn(min = 48.dp)` på knappen om nödvändigt). `onClick`: anropa `onKopPro(activity)`.
4. **Sekundär knapp (dismiss):** text `R.string.pro_inte_nu`, `onClick`: `onStangProDialog()`.
5. **`onDismissRequest`:** samma som «Inte nu» — `onStangProDialog()`.

All text via `stringResource`, inga hårdkodade strängar.

I `MainActivity`, vid `KopListaSkarm`: sätt `onKopPro = { activity -> proKalla.kop(activity) }`.

Parametrar som `arPro` och `onVisaProDialog` får vara oanvända i kroppen om de inte behövs för dialogen — ändra inte ViewModel.

## Exempel
- Gräns nådd, FAB → `proDialogSynlig` true → dialog med titel Pro, förklaring + «Gräns nådd: 15 köp», knapp «Lås upp Pro» och «Inte nu».
- «Inte nu» eller dismiss → `stangProDialog()` → dialog försvinner, listan syns.
- «Lås upp Pro» → `proKalla.kop(activity)` startar (manuellt test på enhet).
